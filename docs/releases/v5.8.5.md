v5.8.4 正式发布后的复核补漏与两处运行时修正。本版**不改变任何防护范围**：12 个 STUN/TURN 端口的 udp+tcp 阻断、WFP 规则、核心路由表的 B1 写入逻辑、`PASSED WITH CAVEAT` 验收口径全部与 v5.8.4 一致；改动集中在「体检结果如何归因」与「仓库文档是否自洽」。

### 一、修复一个会造成虚假「全通过」的体检缺陷

`12-regression.ps1` 的 `Check()` 原本对任何字符串返回值都累加 `PASS`。B1 路由守卫检查在 `binConfigs\config.json` 不存在（v2rayN 未运行）时返回 `SKIP - ...`，于是：

- 控制台打印绿色 `[PASS] B1 STUN route guard ... : SKIP - ...`
- 结果行 `FAIL=0`
- GUI 弹出「全项体检通过」

也就是说，一个**根本没被检查**的守卫被算作已验证。本版改为：

| 返回值 | 计数 | 输出 |
| :--- | :--- | :--- |
| 正常说明字符串 / `$true` | `PASS` | 绿色 `[PASS]` |
| 以 `SKIP` 开头的字符串 | `SKIP`（独立计数） | 灰色 `[SKIP]`，**不计入** PASS / FAIL |
| `$false` / 抛异常 | `FAIL` | 红色 `[FAIL]` |

结果行**仅在 `SKIP>0` 时**追加 ` SKIP=n`，正常运行仍是 `RESULT: PASS=x FAIL=y`，与既有文档、GUI 判定兼容。逻辑复现：正常 / SKIP / 失败各一例 → `pass=1 fail=1 skip=1`、`RESULT: PASS=1 FAIL=1 SKIP=1`。

顺带把 `12` 的 `$V2rayNRoot` 候选表补齐为与 `07` / `18` 一致（增加 `D:\v2rayN-windows-64-desktop\v2rayN-windows-64` 等 `-desktop` 路径）。此前若无 `guard-policy.json` 兜底，B1 检查会指向不存在的 config 并静默退化成 SKIP。

### 二、补齐 `protocol` 字段的遮蔽判定

`lib-stun-guard.ps1` 的 `StunNarrowingKeys` 早已收录 Xray 的 `protocol`（sniffing 结果匹配），但 `Get-StunRuleVerdict()` 没检查它，带 `protocol` 的前置规则会被当成无条件 `matches` → **假 `SHADOWED` 告警**。现并入 `process` / `user` / `source` / … 的收敛循环，判为 `restricted`（caveat）：配置里无法证明排除就显式披露，而不是擅自判定排除。

四种形状复验：`scoped(process) → restricted`、`scoped(protocol) → restricted`、`plain(inboundTag) → matches`、`other inbound → excluded`。真实核心配置结论未漂移：`present / index=5 / shadow=0 / caveat=1`。

### 五、边界与如实披露

1. **本版未实跑 `12-regression.ps1` 全量体检**：它含 10 秒 `pktmon` 抓包、临时 WFP 导出与 geo 文件写入，需提权且有系统副作用。`PASS=27 FAIL=0` 是 v5.8.4 改动前的实机结果；本版以构建门禁、逻辑等价复现、配置级形状探针验证新增逻辑，**不等于整份体检在 v5.8.5 真机跑过**。
2. **防护范围未变**：12 端口 udp+tcp；`udp/443` 与 origin-scoped direct 的 caveat 原样保留；`verify-leak-test.ps1` 的 `PASSED WITH CAVEAT` 三段披露逐字未动。
3. **B1 检测仍只读**：`-Apply` / `-Restore` 一律人工，不在后台自动改 `guiNDB.db`。
4. **生产目录需重新同步**：`-SyncWorkspace` 只同步 `scripts\*.ps1`；在提权同步前，`C:\AI-Net-Guard` 实机跑的仍是 v5.8.4 脚本。
5. **本地 exe 与 Release exe 哈希必然不同**（编译非确定性）；以 Release 中的 `.sha256` 资产为准。

### 升级与部署方式

1. **GUI 升级**：下载 `AI-Net-Guard.exe` 直接运行，点击「应用策略」即可解包部署最新引擎。
2. **管理员命令行平滑同步**：
   ```powershell
   powershell -ExecutionPolicy Bypass -File "C:\AI-Net-Guard\scripts\13-harden-acl.ps1" -Root "C:\AI-Net-Guard" -SyncWorkspace -WorkspaceRoot "<仓库绝对路径>" -SkipVerification
   ```
3. **验证体检**：
   ```powershell
   powershell -ExecutionPolicy Bypass -File "C:\AI-Net-Guard\scripts\12-regression.ps1" -Root "C:\AI-Net-Guard"
   ```
   报告中 `B1 STUN route guard` 应为 `[PASS]` 并附带 caveat 披露；若 v2rayN 未运行，该项应显示灰色 `[SKIP]` 且结果行出现 `SKIP=1`，而**不再**被误算为通过。
