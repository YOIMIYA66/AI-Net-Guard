## AI-Net-Guard v5.9.0 发布说明 (Release Notes)

轻量级安全收敛版本（收敛自 v5.8.9 第二轮复审）：保持单 EXE + 零常驻静态 WFP 架构不膨胀，完整修补了权限前置、锁一致性、Fail-Closed 策略与回滚保护、GUI 增量原子释放、以及 `Protected` 持久化等 10 项细节，并额外修复了 `09-rollback.ps1` 缺少 `-Auto` 开关的参数绑定缺陷。

---

### 一、P0 / P1：权限边界、互斥锁与 Fail-Closed 策略/回滚

1. **SYSTEM 任务注册前全入口强制校验 ACL（#01 · `lib-guard-common.ps1` / `02-killswitch.ps1` / `07-mode.ps1`）**
   - `Get-GuardInstallAclIssues` 新增非盘符根父目录权限检查，并将 `scripts\` 遍历失败计为明确 ACL 问题不再吞异常；
   - `02-killswitch.ps1` 在注册 SYSTEM 自动回滚任务 `AI-Guard-Test-Rollback` 前检查安装目录 ACL，未锁时先执行 `13-harden-acl.ps1 -SkipVerification -SkipRegression` 锁定并复验；
   - `07-mode.ps1` `Install-WatchdogTasks` 入口同样强制校验 `Get-GuardInstallAclIssues`，阻止直接调用 `-InstallTasks`/`-Upgrade` 绕过信任边界。
2. **禁止写锁退化为 `Local\`，并将锁推进至策略读取之前（#02 / #03 · `lib-guard-common.ps1` / `07-mode.ps1` / `14-apply-policy.ps1`）**
   - `Enter-GuardWriteLock` 彻底移除 `Local\AI-Net-Guard-PolicyEngine` 退化路径，固定使用带 `Administrators + SYSTEM` `MutexSecurity` 的 `Global\AI-Net-Guard-PolicyEngine`，且父子重入令牌 `AI_GUARD_LOCK_TOKEN` 绑定锁名与存活宿主 PID；
   - `07-mode.ps1`（除只读 `-Status`）与 `14-apply-policy.ps1` 统一在**读取 `guard-policy.json` 之前**取得 `Global\` 写锁，`07-mode.ps1` 的 `-RemoveTasks` / `-InstallTasks` / `-Upgrade` / GeoIP 刷新全部纳入持锁区并内重读最新策略。
3. **策略 Fail-Closed 与后置更新 `last-good`（#04 · `lib-guard-common.ps1` / `14-apply-policy.ps1` / `GuardPolicy.cs`）**
   - `ConvertFrom-StrictPolicyJson` 拒绝空 `{}` 及显式 `null` 字段；
   - `Read-GuardPolicyStrict` 对已部署主机（存在 `backup\baseline.json`）缺失主策略时不再退回宽松默认，而是优先恢复 `last-good`，均失败则 Fail-Closed；仅在 `14-apply-policy.ps1` 零错误完成应用后调用 `Save-GuardPolicyLastGood`；
   - GUI `GuardPolicy.SaveToFile` 改用临时文件 + `File.Replace` 原子替换。
4. **回滚不静默放开出站、修复 `-Auto` 绑定并按基线还原（#05 / #06 · `09-rollback.ps1` / `Emergency-Rescue.bat`）**
   - 新增 `[switch]$Auto`，修复 `AI-Guard-Test-Rollback` 带 `-Auto` 触发时报错退出的隐蔽缺陷；
   - 基线导出文件缺失或 `netsh advfirewall import` 失败时，**默认不再强制把防火墙改成 `DefaultOutboundAction = Allow`**（返回 `exit 1` 并提示排查，急需断网救援请传 `-ForceAllowOutbound` 或运行 [`Emergency-Rescue.bat`](../../Emergency-Rescue.bat)）；
   - 按 `dnsBackup` 与 `hotplug-ipv6.json` 逐网卡还原 `ms_tcpip6` 绑定；DNS/NRPT/DoH/任务/注册表关键步骤异常全部计入 `$rollbackErrors`，有错误时不归档 `guard-policy.json` 也不清理恢复元数据。
5. **严格核验回滚安全定时器注销（#07 · `14-apply-policy.ps1`）**
   - 注销 `AI-Guard-Test-Rollback` 后强制回读 `Get-ScheduledTask` 复核；若仍残留则记入错误并退出 `5`，防止界面提示成功却在 30 分钟后被定时任务悄然回滚。

### 二、P2：GUI 增量原子释放、CN 校验统一与 `Protected` 持久化

- **GUI 组件互斥锁 + SHA-256 增量释放（#08 · `PayloadAndRunnerService.cs`）**：提取内嵌载荷前先持有 `Global\AI-Net-Guard-PolicyEngine`，通过 SHA-256 跳过未变更文件，变更文件走 `.tmp.<pid>` + `File.Replace` 原子更新。
- **`02-killswitch.ps1` 复用严格 CN CIDR 校验（#09）**：移除正则匹配，改用 `lib-guard-common.ps1` 的 `Get-ValidatedCnPrefixes`。
- **`Protected` 模式持久化锁（#10 · `07-mode.ps1` / `14-apply-policy.ps1`）**：执行 `07-mode.ps1 -Mode Protected` 会写入 `backup\protected-lock.flag`，期间 `AI-Guard-Mode-Event` / `Fallback` 保持锁定不自动恢复国内直连；传入 `-ClearProtectedLock`、在 GUI/CLI 应用开启 `AllowCnDirect` 的策略、或完整回滚后自动清除。
