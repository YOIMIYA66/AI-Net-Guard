## 🚀 AI-Net-Guard v5.7.3 发布说明 (Release Notes)

### 🎨 全链路 Fluent / Lucide 纯矢量体系重构 (Vector-First Visual System)
- **告别低保真卡通 Emoji**：全面淘汰在 Windows 平台带有粗黑描边和不对称比例的 Emoji 字符（如卡通地铁车厢 `🚇`、放大镜 `🔍`、锁 `🔒`、地球 `🌐` 等）。
- **13 组原生 XAML `StreamGeometry` 矢量路径**：全面换血为 Fluent / Lucide 工业级标准微图标。以极具科技感的**双向网络节点总线网关**替换原先的卡通地铁，高 DPI / 4K 缩放无锯齿、无模糊，像素级清晰锐利。
- **现代化视觉卡片与分类计数器**：采用 8px 圆角与浅色轻质微阴影，4 大策略分类（流量分流、DNS 防泄漏、智能路由、系统韧性）新增色彩胶囊矢量徽章与实时特性数量统计。

### 📐 弹性底栏防截断布局 (Elastic Zero-Truncation Layout)
- **消除状态文本截断 Bug**：精简底部按钮尺寸，横向释放超过 150px 呼吸感空间。
- **自适应弹性胶囊药丸 (Elastic Status Pill)**：状态栏重构为动态呼吸指示药丸，支持任意窗口分辨率下的自适应伸缩与文本优雅省略，保证 **0 截断、0 溢出**，悬停呈现完整多行详细解释。

### 🛡️ 官方推荐系统代理模式 (ProxyEnable=0 纯 TUN 模式)
- **官方推荐纯净内核分流**：对于 TUN 模式，确立官方推荐的最佳纯净状态为保持系统代理处于已清除（`ProxyEnable = 0`）。所有出站流量经由 `xray_tun` 虚拟网卡由内核底层捕获分流，彻底杜绝 WinINET HTTP 代理与本地应用程序抢占、端口不匹配（10808/10809）或死代理残留。
- **浅色软强调微光卡片**：去除突兀暗黑条纹，清除推荐状态采用浅绿微光底色与翡翠绿重音线；支持一键在“清除系统代理（官方推荐）”与“临时开启系统代理”之间无缝切换。

### 🌐 原生中英双语即时切换 (Bilingual Localization)
- **免重启双语切换**：主界面右上角新增 `🌐 English` / `🌐 简体中文` 一键即时切换按钮，覆盖 15 项策略卡片、方案预设、遥测卡片与交互弹窗。
- **语言偏好自动持久化**：用户语言选择自动保存至本地配置，下次启动无缝沿用。

### 🩺 全链路回归体检 WFP 规则检测加固
- **精准匹配 Xray 防泄漏规则**：优化底层检测正则为 `block (?:the )?DNS|block (?:tcp|udp)/(?:53|853)`，准确识别 Xray 动态注入的 18 条底层 WFP 规则，彻底消除体检第 4 项误报 `count=0`，实现 24/24 项全绿 PASS。
