## AI-Net-Guard v5.9.5 发布说明 (Release Notes)

**脱敏重发维护版 (Sanitized Release)**：在 `v5.9.4` 全部功能与修复基础之上，基于完成全量脱敏后的代码树重构单文件 `AI-Net-Guard.exe` 与 `AI-Net-Guard-portable.zip`（替换内嵌在压缩包与 EXE 载荷中的历史文档、注释和批处理路径），并固化自动化防泄露门禁，无功能与架构变动。

---

### 一、相较 v5.9.4 的更新内容

1. **内嵌脚本与随附文档全面脱敏**
   - 清理包内 `CURRENT-IMPLEMENTATION.md`、[`15-webrtc-browser-shield.ps1`](../../scripts/15-webrtc-browser-shield.ps1)、[`02-killswitch.ps1`](../../scripts/02-killswitch.ps1)、[`07-mode.ps1`](../../scripts/07-mode.ps1)、[`align-xray-egress.bat`](../../scripts/align-xray-egress.bat) 与 [`align-xray-egress.ps1`](../../scripts/align-xray-egress.ps1) 中遗留的非通用路径与具体示例 IP，统一改用通用安装路径 `C:\AI-Net-Guard` 与 RFC 5737 示例地址（`203.0.113.10` / `198.51.100.10` / `192.168.1.x`），并移除 `align-xray-egress.ps1` 中的硬编码 IP 兜底。
2. **新增自动化防 PII 门禁断言（[`test-stun-ports.ps1`](../../tests/test-stun-ports.ps1)）**
   - 回归门禁扩展至 **60 项**，每次测试与 CI 构建自动扫描仓库源码、文档、脚本与 GUI 文件，阻断个人本机路径或私密 IP 再次进入仓库与发布包。

### 三、从本地仓库同步到 `C:\AI-Net-Guard`（管理员 PowerShell 执行）

将 `C:\path\to\AI-Net-Guard` 替换为你的本地仓库目录后执行：

```powershell
$ws = "C:\path\to\AI-Net-Guard"; $root = "C:\AI-Net-Guard"; powershell -ExecutionPolicy Bypass -File "$ws\scripts\13-harden-acl.ps1" -Root $root -SyncWorkspace -WorkspaceRoot $ws -SkipVerification; & "$root\scripts\07-mode.ps1"; & "$root\scripts\12-regression.ps1"
```
