## AI-Net-Guard v5.9.1 发布说明 (Release Notes)

稳定维护收敛版本：针对 v5.9.0（`ced21ff`）源码对比审查指出的最后 9 项交互边界问题完成小范围修正；保持单 EXE + 零常驻静态 WFP + 三公共库轻量架构不变。自本版本起项目进入日常 Bug Fix 与 Windows 兼容性维护模式。

---

### 一、最小修复清单

1. **P1 #01 · `Protected` 持久化不再跳过 `Ensure-Guard` 自修复（[`07-mode.ps1`](../../scripts/07-mode.ps1)）**
   - 当存在 `backup\protected-lock.flag`（或传入 `-Mode Protected`）时，不再分流跳过 `Ensure-Guard`，而是作为策略覆盖强制设定 `AllowCnDirect = $false` 并照常执行 DNS、IPv6、越权出站 `Allow` 隔离、节点/TUN 同步、STUN 检查与物理网卡显式阻断自愈。
2. **P1 #02 · 未提交策略失败时绝不残留污染后台任务（[`MainWindow.xaml.cs`](../../gui/MainWindow.xaml.cs) / [`14-apply-policy.ps1`](../../scripts/14-apply-policy.ps1) / [`07-mode.ps1`](../../scripts/07-mode.ps1)）**
   - GUI 点击部署/应用时先写入 `backup\guard-policy.pending.json` 并通过 `-PolicyPath` 传入 `14-apply-policy.ps1`；
   - `14-apply-policy.ps1` 在全局锁内快照原 `guard-policy.json`，应用失败或预检未通过时自动还原原策略（初次部署失败则删除未提交文件）并清理 pending 文件；移除 `07-mode.ps1` 越权初始化 `last-good` 的代码，`guard-policy.last-good.json` 严格只在应用零错误完成后更新。
3. **P1 #03 · 修复 `Apply-GuardPolicyToScriptVars` 参数作用域回归（[`07-mode.ps1`](../../scripts/07-mode.ps1)）**
   - 在脚本入口缓存 `$script:CliBoundParams` 与初始默认值，函数内统一查询该快照而非函数局域 `$PSBoundParameters`，并在获取写锁重读策略后双向重算 `-DisableAutoNodeSync`、`-SkipQuarantineAllowRules`、`-SkipStaleProxyHeal`、`V2rayNRoot` 与 `DnsServer`。
4. **P1 #04 · 自动回滚任务避免停止自身（[`09-rollback.ps1`](../../scripts/09-rollback.ps1)）**
   - 携带 `-Auto`（由 `AI-Guard-Test-Rollback` 或 `06-boot-guard.ps1` `AI-Guard-Boot-Guard` 触发）时，跳过对上述宿主任务调用 `Stop-ScheduledTask`，改在恢复收尾后再安全注销，避免回滚刚开始即自我终止。
5. **P1 #05 · 先删尽并回查验证 SYSTEM 任务，再允许解除 ACL（[`14-apply-policy.ps1`](../../scripts/14-apply-policy.ps1) / [`09-rollback.ps1`](../../scripts/09-rollback.ps1)）**
   - `14-apply-policy.ps1` 在 `HardenInstallAcl = OFF` 且 `ZeroResidentMonitor = OFF` 时，推迟至 `-RemoveTasks` 与 `AI-Guard-Test-Rollback` 注销完成后重查全部 `AI-Guard*` 任务确认清零，才允许执行 `13-harden-acl.ps1 -Undo`；`09-rollback.ps1` 仅在无错误、未中止且无残留 `AI-Guard*` 任务时才复位目录 ACL。
6. **P1 #06 · 防火墙基线恢复失败时立即中止后续破坏性回滚（[`09-rollback.ps1`](../../scripts/09-rollback.ps1)）**
   - 非 `-ForceAllowOutbound` 的常规回滚若无法导入防火墙基线，直接中止后续规则删除、原有放行恢复、DNS/IPv6 修改与元数据清理，返回退出码 `1`；强制脱困继续通过 `-ForceAllowOutbound` 与 [`Emergency-Rescue.bat`](../../Emergency-Rescue.bat) 提供。
7. **P2 #07/#08/#09 · Boot Guard ACL 检查、独立 `02-killswitch` 全局锁与严格核心字段校验**
   - [`06-boot-guard.ps1`](../../scripts/06-boot-guard.ps1) `-Arm` 注册 SYSTEM 任务前复用 `Get-GuardInstallAclIssues` 校验目录 ACL；
   - [`02-killswitch.ps1`](../../scripts/02-killswitch.ps1) 独立执行纳入 `Enter-GuardWriteLock` / `finally Exit-GuardWriteLock` 保护；
   - [`lib-guard-common.ps1`](../../scripts/lib-guard-common.ps1) 在 `-IsDeployed` 时启用 `ConvertFrom-StrictPolicyJson -RequireCriticalBools`，拒绝缺少关键布尔开关的残缺 JSON 静默回退宽松默认值。
