## AI-Net-Guard v5.8.4 发布说明 (Release Notes)

质量与可观测性维护版本：针对第三方 review 的 4 项技术意见进行逐条代码复核与针对性修正，把 B1 核心路由守卫正式纳入 `12-regression.ps1` 全链路体检，缓存读写升级为 UTF-8 无 BOM 杜绝解析失效，完善卸载脚本对路由残留的交互提示，并将构建回归门禁断言扩充至 19 项。

**防护范围与 v5.8.3 完全一致，未放宽任何阻断，也未新增阻断；没有改动 WFP 规则与核心路由表的写入逻辑，亦未放宽三态遮蔽判定或 `PASSED WITH CAVEAT` 验收口径。**

---

### 一、复核 review 建议：两项按建议修、两项纠偏后修（不照单全收）

对收到的 4 项 review 意见，我们首先通过比对代码和真机实测确认事实，拒绝盲目套用补丁：

| 项 | 复核结论 | 纠偏与落地措施 |
| :--- | :--- | :--- |
| **P1 `inboundTag` 早返回** | **属实，但影响方向是假阳性** | 原代码在命中 TUN inbound 时直接 `return 'matches'`，跳过了后续针对进程（`process`）和来源的检查。后果是把仅作用于单一进程的放行规则误判为全局遮蔽（`SHADOWED`），而非防护漏报。**修复**：命中 TUN inbound 时仅更新原因文本，继续向下执行 `ip` 与进程限定检查，确保单进程规则正确归入 `restricted` 告警（`caveat`），全局无条件放行才判为 `SHADOWED`。 |
| **P2 缓存编码** | **属实但只影响中文可读性，review 方案有 BOM 陷阱** | 读写同为 ASCII 时因 key 是 `(mtime,length)`，缓存往返并不会失真，只是 Detail 中的中文被替换为 `?`。但若仅按 review 建议把写入改成 `Set-Content -Encoding UTF8`，Windows PowerShell 5.1 会写入 3 字节 UTF-8 BOM，导致读取端的 `StartsWith($stamp)` 前缀匹配快路径**永久失效**。**修复**：读写两侧成对采用 .NET 原生 `UTF8Encoding($false)`，既支持中文往返，又杜绝 BOM 污染。 |
| **P3 卸载闭环提示** | **属实** | `09-rollback.ps1` 清理了 `b1-guard.meta` 缓存，但未提示核心路由表 `guiNDB.db` 中可能残留的 B1 规则。**修复**：新增 10.5 段检测备份目录，若存在备份则显式输出醒目的黄字提示与精确的手动恢复命令 `18-route-stun-guard.ps1 -Restore`；**坚持不自动修改数据库**，避免在 v2rayN 运行时并发改写损坏 SQLite。 |
| **P4 体检覆盖与硬编码** | **属实，但 PASS=26 不成立** | `12-regression.ps1` 顶层有 12 个 Check，其余在适配器循环中动态生成，总数随网卡环境动态变化；GUI 与文档此前硬编码了 "24 项"。**修复**：在 `12-regression.ps1` 中加入 B1 路由守卫检查（`Check 'B1 STUN route guard present in core routing table'`）；同时清理 XAML、C# 后台、本地化字典及中英 README 中全部硬编码数字，统一改为泛化的「全量回归体检」。 |

### 四、边界与技术声明（保持一致披露）

1. **`B1 ACTIVE with 1 caveat` 仍客观存在**：核心路由表中排在 STUN 丢弃规则之前的 `outbound=direct, process=xray/sing-box/self` 规则不限端口与域名，核心自身产生的 STUN 流量仍受其影响。本版实事求是披露这一技术边界，不进行虚假粉饰。
2. **端口覆盖范围未变**：继续严格覆盖 WebRTC / STUN / TURN 标准及主流使用的 12 个端口（3478, 3479, 5349, 5350, 19302-19309，UDP+TCP）。不对非标的 `udp/443` 进行无差别拦截，以保护国内 QUIC/HTTP/3 正常体验。
3. **B1 检测保持只读**：无论是 `07-mode.ps1` 周期巡检还是 `12-regression.ps1` 回归体检，均仅做只读判定，绝不在后台自动修改路由数据库。若需应用或回滚，请在退出 v2rayN 后手动执行 `18-route-stun-guard.ps1 -Apply` 或 `-Restore`。

1. **GUI 升级**：下载最新版 `AI-Net-Guard.exe` 直接运行，点击「应用策略」即可将内置的最新引擎与脚本自动部署解包。


   ```powershell
   powershell -ExecutionPolicy Bypass -File "C:\AI-Net-Guard\scripts\12-regression.ps1" -Root "C:\AI-Net-Guard"
   ```
