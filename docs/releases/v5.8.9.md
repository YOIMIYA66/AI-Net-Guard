## AI-Net-Guard v5.8.9 发布说明 (Release Notes)

安全正确性与可靠性收口版本：修复 `10-sync-node-rule.ps1` 漏传 IPv6 策略问题，并完成静态安全审计核实的 **3 项 P0（ACL 信任链、回滚基线保护、子进程退出码严格传播）+ 5 项高性价比 P1/P2（Fail-Closed 策略解析、跨进程写锁、延后取消回滚、严格 CN CIDR 校验、任务健康精确判定）** 与仓库文档同步。

---

### 一、P0：核心安全边界与可靠性修复

1. **SYSTEM 任务与安装目录 ACL 完整信任链（`lib-guard-common.ps1` / `13-harden-acl.ps1` / `07-mode.ps1` / `12-regression.ps1` / `14-apply-policy.ps1`）**
   - 新增共享库 [`scripts/lib-guard-common.ps1`](../../scripts/lib-guard-common.ps1)，`Get-GuardInstallAclIssues` 改为**递归检查 `scripts\` 全目录树、关键 `backup\` 策略/白名单文件及 NTFS `ReparsePoint`（符号链接/目录联接）**；
   - `14-apply-policy.ps1` 调整执行顺序为 **「先锁定 ACL → 校验成功 → 再注册 SYSTEM 计划任务」**；当开启 `ZeroResidentMonitor` 时禁止跳过目录 ACL 加固，若 ACL 加固失败则拒绝注册 SYSTEM 任务。
2. **回滚脚本保留原有防火墙基线并校验导入结果（`09-rollback.ps1`）**
   - 校验 `netsh advfirewall import` 的 `$LASTEXITCODE`：基线导入成功时**不再无条件覆盖为 `DefaultOutboundAction = Allow`**（避免用户原本为 `Block` 的策略被误放开）；仅在无基线/导入失败或显式指定紧急开关 `-ForceAllowOutbound` 时放开出站；
   - 发生回滚错误时不提前归档 `baseline.json`，并返回非零退出码 `1`。
3. **彻底禁止底层失败却向 GUI/CLI 报成功（`14-apply-policy.ps1`）**
   - 新增 `Invoke-GuardChild` 统一校验 `10-sync-node-rule.ps1`、`07-mode.ps1`、`13-harden-acl.ps1` 等所有子进程退出码；任一步失败计入 `$applyErrors`、输出明确错误并以 **`exit 5`** 退出，不再打印 `[SUCCESS]`。

---

### 二、P1 / P2：状态一致性、策略 Fail-Closed 与联动修复

- **A1 修复 + A3 IPv6 安全边界说明**：`10-sync-node-rule.ps1` 同步读取 `guard-policy.json` 中的 `DisablePhysicalIpv6` 布尔值并传给 `Sync-ForeignPhysicalBlockRule -BlockPhysicalIpv6`，解决切为 Compatible（放开 IPv6）后手跑同步脚本意外重新拉起 IPv6 拦截规则的问题。同时明确提示：**关闭 `DisablePhysicalIpv6` 在恢复物理网卡 IPv6 连通性的同时，也会取消物理网卡 IPv6 侧 `2000::/3` 的显式 WFP 阻断兜底**（仅推荐确实需要原生 IPv6 场景开启）。
- **#04 策略损坏 Fail-Closed 与严格类型检查（`lib-guard-common.ps1` / `07-mode.ps1` / `12` / `14`）**：`Read-GuardPolicyStrict` 校验所有布尔字段必须为真实 JSON boolean（拒绝 `"false"` 字符串强转成 `$true` 的陷阱）；每次成功读取后原子写入 `backup\guard-policy.last-good.json`；主文件损坏时优先恢复 `last-good`，均损坏则进入 **Fail-Closed**（`AllowCnDirect=$false`、`AllowLan=$false`、`14-apply-policy.ps1` 拒绝写入系统配置）。
- **#05 跨进程写入互斥锁（`lib-guard-common.ps1` / `07` / `09` / `10` / `14`）**：通过 `Global\AI-Net-Guard-PolicyEngine` 跨进程 Mutex + `AI_GUARD_LOCK_TOKEN` 父子重入令牌串行化所有写操作，消除 GUI、网络事件任务、定时巡检与回滚的并发写竞争。
- **#08 延后注销 30 分钟自动回滚保护**：首次部署在所有收尾步骤（含节点同步、ACL 加固、任务注册）均零错误通过后才注销 `AI-Guard-Test-Rollback`。
- **#11 严格 CN IPv4 CIDR 校验**：`Get-ValidatedCnPrefixes` 使用 `IPAddress.TryParse`、限制 `/8../32`、剔除保留/环回/RFC1918/组播段并归一化去重，拒绝 `0.0.0.0/0` 等异常条目。
- **#12 任务健康精确判定**：`17-autorepair-task.ps1` 仅在任务处于 `Ready`/`Running` 且上次运行结果正常（`0`/`267009`/`267011`）时判为健康；`watchdog.ps1` 仅在 `$code -eq 0` 时记录 `ok`。
- **文档收口**：更新 `docs/REPO-LAYOUT.md` 版本索引、`README_EN.md` 验收口径及 `lib-foreign-block.ps1` 注释。
